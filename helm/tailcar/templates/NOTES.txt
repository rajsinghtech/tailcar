Thank you for installing {{ .Chart.Name }}!

Your release is named {{ .Release.Name }}.

The Tailcar operator has been deployed to namespace {{ .Release.Namespace }}.

To get started:

1. Create an OAuth secret with your Tailscale credentials:

   kubectl create secret generic my-tailnet-oauth \
     --namespace {{ .Release.Namespace }} \
     --from-literal=client-id='<your-client-id>' \
     --from-literal=client-secret='<your-client-secret>'

2. Create a Tailnet resource:

   cat <<EOF | kubectl apply -f -
   apiVersion: tailcar.rajsingh.info/v1alpha1
   kind: Tailnet
   metadata:
     name: my-tailnet
     namespace: {{ .Release.Namespace }}
   spec:
     tailnetName: "-"
     oauthSecretRef:
       name: my-tailnet-oauth
       namespace: {{ .Release.Namespace }}
     tailscale:
       tags:
         - "tag:k8s"
   EOF

3. Annotate your pods to enable Tailscale injection:

   apiVersion: v1
   kind: Pod
   metadata:
     name: my-app
     annotations:
       tailcar.rajsingh.info/inject: "true"
       tailcar.rajsingh.info/tailnet: "my-tailnet"
   spec:
     containers:
     - name: app
       image: nginx
